# 火山引擎小魔推竞品功能差距开发功能点

更新时间：2026-05-26

## 1. 背景

本次走查对象为 `https://volcengine.xiaomotui.com/#/` 商家后台。已逐个点击对方左侧菜单、顶部任务中心、账号下拉，以及基础版/连锁版切换后的新增页面。

结论：我们当前后台菜单覆盖面更广，但核心商家运营链路多数仍是通用管理后台实现；对方在真实运营流程、剪辑生产力、场景配置、内容库额度、商家账号商业化能力上更完整。

## 3. P0 必做功能

### 3.1 场景配置矩阵

现状：

- 我们已有 `活动管理 / 场景配置`，但主要是场景 CRUD。
- 对方是门店级配置矩阵，是整个扫码/碰一碰业务的核心配置台。

开发功能点：

- 门店配置列表
  - 按门店展示一行配置数据。
  - 支持门店名称、状态、创建时间等筛选。
  - 支持批量设置。
- 配置矩阵列
  - 扫码体验
  - 短视频平台
  - 图文发布
  - 评价文案
  - 打卡配置
  - 关注门店账号
  - 点赞/分享
  - 优惠团购
  - Wi-Fi
  - 添加微信
  - 自定义链接
  - e代驾点击
  - 状态
  - 操作
- 平台配置
  - 抖音
  - 快手
  - 小红书
  - 视频号
  - 朋友圈
  - 携程
  - 大众点评
- 配置弹窗
  - 短视频平台配置
  - 图文发布配置
  - 点评图文配置
  - 打卡配置
  - 关注配置
  - 点赞分享配置
  - 团购商品关联
  - Wi-Fi 配置
  - 微信名片配置
  - 自定义链接配置
  - 碰一碰功能开关配置

验收标准：

- 能以门店为维度查看所有扫码触点配置状态。
- 能单门店配置，也能批量配置。
- 每个配置项有独立保存、回显和启停状态。
- 页面不是普通场景表，而是矩阵式配置台。

### 3.2 新建剪辑工作台

现状：

- 我们已有 `视频创作 / 新建剪辑`，当前是三步向导：选择素材、选择模板、配置发布。
- 对方是完整剪辑编辑器。

开发功能点：

- 剪辑模式
  - 一键成片
  - 批量混剪
  - 分镜剪辑
- 模式说明
  - 展示适用人群、操作步骤、能力差异。
- 工程操作
  - 我的模板
  - 保存为模板
  - 保存剪辑工程
- 分镜管理
  - 镜头列表
  - 添加镜头
  - 单镜头素材管理
  - 单镜头时长设置
  - 消除原声
  - 转场随机/滤镜
- 剪辑配置
  - 全局设置
  - 字幕显示
  - 分镜字幕/全局字幕
  - 字幕样式配置
  - 配音演员
  - 镜头配音
  - 音量调整
  - 背景音乐
  - 标题文案
  - 贴纸
  - 视频比例：9:16、16:9、1:1
  - 背景填充
  - 视频时长：按视频时长、按配音时长
  - 帧率：25FPS、30FPS、60FPS
  - 颜色调整：对比度、饱和度、亮度、色度
- 预览
  - 可点击预览视频。
  - 可查看成品样式。

验收标准：

- 用户进入页面后能选择三种剪辑模式。
- 分镜剪辑能添加多个镜头并配置每个镜头素材。
- 能保存工程和模板。
- 剪辑配置覆盖字幕、配音、音乐、贴纸、比例、帧率、颜色。

### 3.3 素材管理升级

现状：

- 我们已有素材管理，但偏通用素材列表和上传。
- 对方素材管理支持文件夹树和多类生产素材。

开发功能点：

- 文件夹树
  - 新建文件夹
  - 重命名文件夹
  - 删除文件夹
  - 移动素材到文件夹
- 素材分类页签
  - 视频
  - 图片
  - 背景音频
  - 旁白配音
  - 拍摄指南要求
  - 回收站
- 上传能力
  - 上传视频
  - 本地上传
  - 支持 `.mov`、`.mp4`、`.3gp`
  - 单文件大小限制提示，例如 300M
- 筛选能力
  - 素材名称搜索
  - 使用状态
  - 只查看 AI 视频
- 批量能力
  - 全选
  - 批量移动
  - 批量删除
  - 回收站恢复/彻底删除

验收标准：

- 素材可以按文件夹和类型管理。
- 视频、图片、音频、配音、拍摄指南不是混在一个列表里。
- 支持回收站和批量移动。

### 3.5 账号商业化能力

现状：

- 我们顶部账号只有账号设置和退出登录。
- 对方有修改密码、卡密激活、基础版/连锁版切换。

开发功能点：

  - 卡密输入框

  - 红包余额

验收标准：

- 账号下拉具备修改密码、卡密激活、版本切换。
- 卡密激活接入权益/充值模型。
- 版本切换后菜单和权限实时变化。

## 6. 我们已有但对方菜单未明显展示的模块

这些模块可以保留，但不是本次竞品补齐的优先对象：

- 设备管理
- NFC 管理
- 优惠券
- 推广管理
- 数据统计
- 视频模板库
- 内容管理
- 商户管理
- 系统管理

- 不要因为这些模块存在就认为功能领先。

## 9. 风险与注意事项

- 不要只补菜单。竞品优势主要在页面深度和业务闭环。
- 场景配置和成品库会牵涉后端模型，需要先定数据结构。
- 剪辑工作台复杂度高，建议先做 UI 和工程保存，再逐步接入真实生成能力。
- 连锁版和基础版要从权限、菜单、数据范围一起设计。
- 首页和操作手册属于体验层，可以并行做，但不应压过 P0 核心链路。
