### 2.2 视频中暴露的「系统要求 / 期望能力」

把视频里的所有 UI / 动作翻译成系统需求，可以整理为：

1. **硬件触发层**：NFC 标签可被 iOS 识别 → 触发 Native 跳转（Safari / 小程序 / Web Clip）
2. **Wi-Fi 一键连接**：SSID + 密码展示给用户手动复制，或直接走 iOS 13+ 起的「Wi-Fi 接入」配置
3. **多平台分发**：抖音 / 快手 / 小红书图文 / 小红书视频 / 朋友圈图文 / 朋友圈视频 / 视频号 / 自定义
4. **多平台打卡点评**：抖音 / 高德 / 百度 / 美团 / 大众点评，每个平台对应一套 AI 模板 + 配图
5. **AI 内容生成**：根据商家 + 商品，自动生成图片 + 文案
6. **团购导流**：抖音 / 美团的团购券链接、销量展示、抢购按钮
7. **私域沉淀**：加微信（个人号二维码）/ 加 QQ / 加企业微信号
8. **营销活动**：转盘抽奖、节日活动（端午）
9. **一对一商家配置**：每个 NFC 标签绑定一个商家资料、若干文案模板

## 三、视频暴露的现存问题（按严重度排序）

### 3.1 P0 - 安全与合规

| # | 问题 | 视频证据 | 影响 |
|---|---|---|---|
| P0-1 | **裸 IP + HTTP** | 浏览器导航栏始终显示「不安全 — 121.40.163.187 / 40.163.187」 | iOS 会要求用户二次确认打开，部分浏览器直接拦截；合规风险（个人信息保护法、广告法） |
| P0-2 | **Wi-Fi 密码明文存放** | 「Wi-Fi: LI / 密码: liyu123456」直接打印在页面上 | 一旦访客拿手机拍屏或长按，便可永久盗用商家网络；线上泄露等于变相公布商业 Wi-Fi |
| P0-3 | **强制「长按保存图片」** | 「请长按保存每个图片」配合「去点评」按钮 | 体验割裂（图片含二维码水印时还会被截断） |
| P0-4 | **草稿、销量等数据可信度差** | 每张团购卡都是「已售 999」、H5 localStorage 草稿 | 商户上传销量造假会被平台风控 |

### 3.2 P1 - 体验与转化

| # | 问题 | 视频证据 | 影响 |
|---|---|---|---|
| P1-1 | **多步串联、断点多** | 抖音 → 长按 → 切美团 → 加载草稿 → 加载图片 → 写评价，每换一次平台都要回到原 H5 主页 | 用户漏斗损失 30%+，尤其是中老年商家用户 |
| P1-2 | **Native 跳不出去** | 整个流程都困在 Safari 内，无法调用抖音 / 小红书 / 美团 App 的开放能力 | 平台 API 不开放，H5 模拟是无奈之举，但应减少依赖 |
| P1-3 | **AI 文案「模板化」痕迹明显** | 反复出现「蜜雪冰城 ... 茶底清新 ... 入口绵密 ...」结构相同句式 | 平台风控算法已能识别 AIGC 内容，统一模板容易被打回 |
| P1-4 | **图片+素材来源单一** | 一家店只看到一组固定风格的图，没有商家店铺照、菜品照、实景照 | 用户对「营销感太强」反感 |
| P1-5 | **抽奖/活动缺合规机制** | 「端午活动」转盘没有任何弹窗提示概率、加注条款 | 涉嫌违反《反不正当竞争法》第八条「抽奖式有奖销售」最高奖金额不得超过 5 万元 |

### 3.3 P2 - 商家侧能力缺位

| # | 问题 | 视频证据 | 影响 |
|---|---|---|---|
| P2-1 | **商家看不到自己数据** | 整段视频都是消费者视角，没有「商家后台」画面 | 商家无法复盘 ROI，难以续费 |
| P2-2 | **NFC 标签只能配一个 URL** | 演示卡就是一张静态签，没有多商家 / 多活动动态切换 | 标签复用率低、成本高 |
| P2-3 | **不支持 SaaS 化、商家自助开通** | 演示里默认是平台方预制好标签给商家 | 无法规模复制 |

## 四、本系统（小魔推 / xiaomotui）的改进方案

> 全部建议在「复刻 volcengine.xiaomotui.com 后台」的并行开发方案下追加，不破坏现有结构，按 P0 → P1 → P2 推进。

### 4.1 P0 - 必须先解决的安全合规（建议 1-2 周）

1. **HTTPS + 域名 + 备案**
   - 后端 `nginx` / `docker-compose.prod.yml` 强制 301 → 443。
   - 申请备案域名（建议 `m.xiaomotui.cn` 用于 NFC landing）。
   - 取消「不安全」标签是合规起点；视频里的人看到不安全提示会下意识退出。
2. **Wi-Fi 不要裸出密码**
   - 优先用 iOS Wi-Fi Access Point Configuration（NFC NDEF 写入 `application/vnd.apple.wifi-qrconnect+xml`）实现「碰一下就连接」。
   - Android 用 Wi-Fi Easy Connect（DPP）。
   - 后台只在「调试模式」显示密码。
3. **AI 文案合规过滤**
   - 后端调模型时强制加 `合规 prompt`：「不出现'最''第一''绝对化用语'」。
   - 输出端加二级关键词扫描（极限词库 + 平台违禁词库）。
   - 加 `human_review` 字段，要求商家后台一键驳回。
4. **团购销量、抽奖合规**
   - 后端把销量改为「实时取平台 API」，不存前端静态值。
   - 抽奖模块接入活动模板，活动创建页强制展示「奖品价值上限 50000 元」校验。

### 4.2 P1 - 体验与转化（建议 2-4 周）

1. **Native 引导壳 + 一键任务中心**
   - 提供一个 iOS App Clip / Android H5 Wrapper，「碰一碰」直接打开 Clip 而不是 Safari。
   - Clip 内一次性给出「今日任务」：`一键打卡（5 平台）→ 一键发视频（3 平台）→ 一键加私域」，单次完成率 >80%。
2. **AI 素材库**
   - 后台新增 `素材中心`：商家实拍照片、菜单 PDF、AI 文生图结果都入库，每个任务按「平台 + 商品 + 用户人设」混排。
   - 模板模型升级为「向量 + 强化学习」，让小红书和朋友圈的文案差异化。
3. **多平台调度器**
   - 后端新增 `dispatcher` 队列：接收任务 → 拆分到各平台 worker（抖音开放平台 / 小红书 / 微信开放平台）。
   - 提供 「失败重试」+「异步回调」，用户离开页面也不影响。
4. **平台 Native 优先**
   - 用户端只做轻量壳：评论发布跳到平台官方 App，由用户在官方 App 完成「点击发表」按钮（合规且真实）。
   - H5 仅负责「任务编排 + 跳板」。

### 4.3 P2 - 商家侧能力（中长期，4-8 周）

1. **商家后台完整复刻 + 数据看板**
   - 已开始复刻 volcengine.xiaomotui.com 后台，建议补齐：
     - 「NFC 设备管理」：标签 ID、绑定店铺、最近一次被触发时间。
     - 「活动统计」：今日 / 本周 / 本月 触发次数、平台分布、转化漏斗。
     - 「ROI 看板」：NFC 标签触发 → 团购券核销 → 实际到店消费金额。
2. **SaaS 化开通**
   - 商家自助扫码开通、收费（按月 / 按触发次数 / 按团购 GMV 抽佣）。
   - 多店铺多组织支持。
3. **NFC 标签程序化下发**
   - 后台表单 → 调用 NFC 写卡 SDK（NTAG215 / 424 DNA）→ 一键烧录 → 快递面单回传。
   - 后续运营：标签可动态改 url，无需重写。

## 五、关键复刻 → 改进的思考

视频里的「人气好店」本质是 **POI 营销 SaaS**：商家付年费 → 平台派发 NFC 标签 → 消费者碰一碰 → 自动种草 / 打卡 / 抽佣。本系统（小魔推 / xiaomotui）已经走在类似赛道。

下一步演进的可选方向有三：

| 方向 | 描述 | 落地成本 | 壁垒 |
|---|---|---|---|
| **A. 工具型** | 只做后台 + AI 工具，标签 / 商家关系由客户自己维护 | 低 | 低 |
| **B. SaaS 型** | 平台派标签 + 商家自服务 + 抽佣 + 数据看板 | 中 | 中 |
| **C. 生态型** | 联合抖音 / 美团 / 小红书做「官方认证代运营 + POE 流量分发」 | 高 | 高 |

短期建议先走 **B**（视频里的功能 + 商家后端 + 数据闭环），中长期看机会接入 **C**。
